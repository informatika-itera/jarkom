1. Konsep Dasar & Arsitektur VLAN

Broadcast Domain, Isolasi Trafik, dan Klasifikasi Tipe VLAN

Virtual LANs (VLANs): Motivasi

Dinamika jaringan lokal berskala besar memunculkan kendala ketika jumlah host bertambah dan pengguna berpindah secara dinamis.

Permasalahan Domain Broadcast Tunggal (Single Broadcast Domain):

  • Luapan Trafik Broadcast: Frame broadcast layer-2 (ARP request, DHCP discovery, flooding) wajib diteruskan ke seluruh port switch.
  • Penurunan Efisiensi: Beban interupsi CPU setiap host meningkat untuk memproses paket broadcast yang tidak relevan.
  • Risiko Keamanan & Privasi: Trafik sensitif rentan disadap (packet sniffing) tanpa adanya isolasi logis antar-divisi.
Solusi: Segmentasi VLAN memecah domain broadcast besar menjadi domain-domain kecil yang terisolasi.
Infografis Akademis: Dampak luapan broadcast pada LAN tunggal vs isolasi menggunakan VLAN
Jelaskan bahwa broadcast domain yang terlalu besar adalah musuh utama performa jaringan lokal.

Motivasi Administratif

Dalam organisasi berskala menengah hingga besar, penempatan ruang kerja pengguna sering kali tidak selaras dengan batasan fisik jaringan kabel.

Studi Kasus Relokasi Kerja:

  • Seorang staf/peneliti dari Departemen Informatika dipindahtugaskan ke ruang kerja di Gedung Teknik Elektro.
  • Secara fisik, komputer staf tersebut terhubung ke switch lokal di Gedung Elektro.
  • Secara logis, perangkat harus tetap berada di subnet VLAN 10 (Informatika) agar dapat mengakses server dan file sharing internal departemennya.
Solusi Administratif: Administrator cukup mengalokasikan port switch di Gedung Elektro ke VLAN 10 melalui konfigurasi software. Tidak diperlukan penarikan kabel fisik baru lintas gedung.
Infografis Akademis: Fleksibilitas keanggotaan logis VLAN lintas gedung melalui link Trunk
Gambarkan analogi kepindahan kantor tanpa perlu menarik ulang kabel fisik melintasi gedung.

Port-Based VLANs

Switch terkelola (managed switch) memungkinkan pembagian port fisik ke dalam beberapa Virtual LANs secara independen.

Prinsip Kerja Port-Based VLAN (Static VLAN):

  • Setiap antarmuka (port) fisik switch dikaitkan secara manual oleh administrator ke satu nomor VLAN tertentu.
  • Switch fisik tunggal bertindak seolah-olah menjadi beberapa switch virtual mandiri yang tidak saling terhubung secara fisik.
  • Contoh Alokasi Port:
    • Port 1–8: VLAN 10 (Teknik Elektro)
    • Port 9–16: VLAN 20 (Teknik Informatika)
    • Port 17–24: VLAN 30 (Administrasi)
Karakteristik: Penentuan keanggotaan didasarkan murni pada nomor colokan fisik (port) di mana kabel perangkat ditancapkan.
Infografis Akademis: Partisi satu switch fisik menjadi tiga switch virtual berbasis port
Port-based VLAN adalah metode paling umum dan paling mudah dikonfigurasi pada switch Cisco maupun vendor lain.

Traffic Isolation & Dynamic Membership

Dua pilar fundamental dalam implementasi VLAN adalah isolasi keamanan di Layer 2 dan fleksibilitas penentuan keanggotaan:

  • Isolasi Trafik (Traffic Isolation): Frame dari port 1–8 (VLAN 10) hanya beredar di lingkungan VLAN bersangkutan. Komunikasi langsung Layer 2 diblokir secara total dan tidak akan bocor ke VLAN lain.
  • Penerusan Lintas VLAN (Forwarding Between VLANs): Untuk menghubungkan komunikasi antar-VLAN yang berbeda subnet, paket wajib diteruskan melalui proses Routing (Layer 3).
  • Keanggotaan Dinamis (Dynamic Membership): Selain penetapan statis per port, anggota VLAN dapat ditentukan dinamis berdasarkan Alamat MAC host menggunakan server VMPS atau standar IEEE 802.1X.
Perkembangan Teknologi: Switch enterprise modern memadukan fungsi switching Layer 2 dan routing Layer 3 ke dalam satu perangkat tunggal: Switch Layer 3 (Multilayer Switch).
Infografis Akademis: Pemisahan trafik Layer 2 antar-VLAN & keharusan routing Layer 3
Tekankan bahwa VLAN memisahkan jaringan di Layer 2. Tanpa perangkat Layer 3, PC beda VLAN tidak akan pernah bisa saling ping.

VLANs Spanning Multiple Switches

Dalam topologi jaringan kampus atau gedung bertingkat, host-host dalam satu VLAN sering kali terhubung ke switch fisik yang berlainan.

Mekanisme Port Trunk & Ekstensi VLAN:

  • Port Trunk (Trunk Port): Port antarmuka khusus yang mampu membawa trafik dari banyak VLAN sekaligus melalui satu link transmisi fisik tunggal.
  • Penandaan Frame (Frame Tagging): Frame yang melintasi link trunk disisipkan label identitas berupa Tag 802.1Q (berisi VLAN ID) agar switch penerima mengenali kepemilikan VLAN frame tersebut.
  • Penghapusan Tag (Untagging): Sebelum diteruskan ke PC penerima di port Access tujuan, tag 802.1Q dilepas sehingga PC tetap menerima frame Ethernet standar.
Efisiensi: Menghilangkan keharusan menarik kabel fisik terpisah untuk setiap VLAN antar-switch (cukup 1 kabel trunk bersama).
Infografis Akademis: Alur penandaan tag 802.1Q saat frame melintasi kabel Trunk antar-switch
Jelaskan peran link trunk: daripada menarik 1 kabel untuk tiap VLAN, cukup 1 kabel trunk untuk membawa semua VLAN.

802.1Q VLAN Frame Format

Standar industri IEEE 802.1Q menyisipkan bidang Tag tambahan sebesar 4 Byte (32 Bit) tepat di antara alamat MAC Sumber dan kolom Tipe/Panjang:

  • TPID (Tag Protocol Identifier - 2 Byte): Bernilai heksadesimal 0x8100 sebagai penanda bahwa frame memuat tag 802.1Q.
  • TCI (Tag Control Information - 2 Byte):
    • Prioritas / CoS (3 Bit): Menentukan level antrean QoS (standar 802.1p, nilai 0–7).
    • CFI / DEI (1 Bit): Canonical Format Indicator untuk kompatibilitas Token Ring dan drop indicator.
    • VLAN ID / VID (12 Bit): Mengidentifikasi nomor VLAN. Rentang 12 bit menghasilkan 4096 ID (1–4094 usable).
  • FCS / CRC Dihitung Ulang (4 Byte): Karena panjang dan konten frame berubah, nilai checksum pada ekor frame wajib dikalkulasi ulang.
Catatan: Tagging 802.1Q hanya menambah overhead 4 byte, jauh lebih hemat dibanding enkapsulasi Cisco ISL (30 byte).
Infografis Akademis: Anatomi Tag 4-Byte IEEE 802.1Q dan penempatan pada frame Ethernet
Soroti bahwa VLAN ID berukuran 12 bit (2^12 = 4096 kemungkinan ID, 1-4094 usable).

EVPN: Ethernet VPNs (VXLANs)

Pada skala Cloud dan Data Center modern, batas 4.094 VLAN konvensional tidak lagi mencukupi. Digunakanlah EVPN dan VXLAN:

  • Switch Layer 2 terhubung secara logis melintasi jaringan Layer 3 menggunakan IP sebagai underlay.
  • Frame Ethernet L2 dienkapsulasi ke dalam paket UDP/IP dengan VXLAN Network Identifier (VNI) 24-bit (~16 juta segmen jaringan).
  • Menerapkan paradigma Overlay Network (L2 di atas L3), memungkinkan migrasi Virtual Machine (VM) antar-server data center tanpa putus koneksi.
  • BGP EVPN bertindak sebagai control plane untuk mendistribusikan informasi keterjangkauan host secara efisien.
Arsitektur VXLAN & EVPN: Enkapsulasi L2 Overlay di Atas Underlay L3 IP Fabric
Ini adalah wawasan teknologi terkini: VXLAN menyelesaikan keterbatasan 4094 VLAN di lingkungan data center modern.

Overview: Switch Tanpa VLAN

Kondisi operasional default switch pabrikan sebelum dikonfigurasi VLAN:

  • 1 Collision Domain per port: Setiap port memiliki collision domain terisolasi (full duplex).
  • 1 Broadcast Domain raksasa: Semua port tergabung dalam satu domain broadcast yang sama (default VLAN 1).
  • Semua host berada dalam satu subnet IP yang sama.
  • Setiap host dapat berkomunikasi langsung satu sama lain tanpa memerlukan bantuan router.
Switch default: Satu domain broadcast melingkupi seluruh port

Overview: Switch Dengan 2 VLAN

Setelah switch dikonfigurasi dengan 2 VLAN berbeda (misal VLAN 10 Merah dan VLAN 20 Biru):

  • Terbentuk 2 Broadcast Domain terpisah secara logikal di dalam satu kotak switch fisik.
  • Paket broadcast dari VLAN Merah hanya disebarkan ke port-port anggota VLAN Merah.
  • Tiap VLAN mewakili subnet IP berbeda (contoh: 192.168.10.0/24 vs 192.168.20.0/24).
  • Host di VLAN Merah tidak bisa langsung berkomunikasi ke VLAN Biru.
Pemisahan broadcast domain menjadi dua segmen mandiri

Rangkuman Konsep: Apa itu VLAN?

VLAN adalah pengelompokan logik dari perangkat-perangkat jaringan yang terhubung ke port switch, seakan-akan berada pada segmen fisik terpisah.

  • VLAN dapat diberi nama untuk kemudahan manajemen (contoh: VLAN 10 Sales, VLAN 20 HRD).
  • Pada Switch: Administrator membuat VLAN dan memetakan port ke VLAN tersebut.
  • Pada Host: Host dikonfigurasikan dengan alamat IP sesuai subnet VLAN bersangkutan.
Rumus Utama:
1 VLAN = 1 Broadcast Domain = 1 Subnet IP Terpisah.
Konsep dasar pemetaan VLAN pada port switch

Keuntungan VLAN (1/2)

Security & Cost Reduction

1. Peningkatan Keamanan (Security):

  • Data sensitif (divisi Keuangan/SDM) dapat dipisahkan secara broadcast dari pengguna umum.
  • Mencegah serangan packet sniffing dan unauthorized broadcast across divisions.

2. Penghematan Biaya (Cost Reduction):

  • Tidak perlu membeli switch fisik terpisah untuk setiap divisi baru.
  • Satu switch fisik berkapasitas tinggi dapat melayani puluhan grup kerja berbeda.
Manfaat keamanan dan efisiensi pengadaan perangkat keras

Keuntungan VLAN (2/2)

Performance & Flexibility

3. Performa Lebih Tinggi:

  • Mengecilkan ukuran broadcast domain mengurangi beban CPU perangkat dan menghemat bandwidth link.

4. Efisiensi Proyek & Manajemen:

  • Mempermudah pengelolaan QoS (prioritas trafik multimedia / suara).

5. Fleksibilitas Geografis:

  • Karyawan beda ruangan/lantai tetap berada di satu grup VLAN yang sama tanpa pemindahan kabel.
Optimalisasi alur trafik dan fleksibilitas tim kerja

Karakteristik VLAN ID

Penomoran VLAN pada switch Cisco terbagi ke dalam dua rentang (range) utama:

  • Normal-range VLAN (1 – 1005):
    • ID 1002–1005 dicadangkan untuk Token Ring & FDDI.
    • VLAN 1 dan 1002–1005 otomatis dibuat dan tidak bisa dihapus.
    • Konfigurasi range normal tersimpan di dalam file vlan.dat pada memori flash switch.
  • Extended-range VLAN (1006 – 4094):
    • Digunakan oleh Enterprise besar dan ISP (Metro Ethernet).
    • Tersimpan langsung di dalam running-config switch (NVRAM).
Rentang nomor VLAN normal vs extended pada Cisco IOS
Jelaskan letak file vlan.dat pada flash: saat menghapus startup-config, vlan.dat TIDAK terhapus otomatis.

Tipe-Tipe VLAN (1/2)

Klasifikasi fungsional VLAN dalam arsitektur kampus/perusahaan:

  • Data VLAN (User VLAN):
    Dikhususkan untuk membawa trafik data yang dihasilkan pengguna biasa (web browsing, email, transfer file).
  • Default VLAN:
    Pada switch Cisco, semua port pada kondisi bawaan pabrik merupakan anggota dari VLAN 1. Default VLAN tidak dapat diganti namanya maupun dihapus.
  • Native VLAN:
    VLAN yang dialokasikan khusus pada port 802.1Q trunk untuk membawa frame yang tidak diberi tag (untagged frames) demi kompatibilitas perangkat lama.
Data VLAN, Default VLAN 1, dan Native VLAN pada switch

Tipe-Tipe VLAN (2/2)

  • Management VLAN:
    VLAN yang dialokasikan khusus untuk mengakses manajemen switch. IP address switch (SVI interface vlan X) dikonfigurasikan di sini agar administrator dapat me-remote switch via SSH / HTTPS dengan aman.
    Best Practice Keamanan: Jangan gunakan VLAN 1 sebagai Management VLAN!
  • Voice VLAN:
    VLAN khusus untuk mengalirkan trafik IP Telephony (VoIP). Memerlukan pengaturan QoS prioritas tinggi dan jaminan latency rendah.
Pemisahan jalur Management dan Voice untuk keamanan & stabilitas

Lebih Dalam: Voice VLAN

Trafik panggilan suara (VoIP) membutuhkan penanganan istimewa (QoS) di dalam jaringan karena sangat sensitif terhadap gangguan:

Jaminan Bandwidth

Membutuhkan bandwidth stabil tanpa fluktuasi agar audio tidak patah-patah.

Toleransi Latency

Delay transmisi end-to-end harus berada di bawah 150 ms.

Prioritas Antrean

Frame suara harus memiliki nilai 802.1p CoS tinggi (CoS 5) di switch queue.

Penerapan Nyata: Satu port switch terhubung ke IP Phone, lalu PC dicolokkan ke port switch di belakang IP Phone. Switch secara cerdas membedakan Voice VLAN (tagged) dan Data PC (untagged) pada kabel tunggal tersebut.
Jelaskan konfigurasi switchport voice vlan 150 pada port yang menyambung ke Cisco IP Phone.

VLAN Membership (Keanggotaan)

1. Static VLAN Membership:

  • Port switch dikonfigurasi secara manual oleh network engineer.
  • Lokasi fisik port menentukan keanggotaan VLAN (Port 1–2 = VLAN 10, Port 3 = VLAN 20). Paling stabil dan umum digunakan.

2. Dynamic VLAN Membership:

  • Keanggotaan diatur otomatis oleh server VMPS (VLAN Membership Policy Server) atau 802.1X.
  • Port ditentukan berdasarkan MAC Address atau kredensial user saat perangkat terhubung.

2. VLAN Trunking & Protokol Tagging

Link Trunk, Format Frame IEEE 802.1Q, ISL, dan Negosiasi Dinamis DTP

Konsep TRUNK Link

Trunk adalah link penghubung point-to-point antara Switch ke Switch, atau Switch ke Router.

  • Trunk berfungsi memperluas jangkauan VLAN melintasi beberapa switch fisik.
  • Satu kabel Trunk fisik mampu membawa trafik dari berbagai macam VLAN secara bersamaan.
  • Agar frame tidak tertukar antar VLAN saat melintas, frame disisipkan label identitas VLAN (Tagging).
  • Dua teknologi tagging L2: Cisco ISL (legacy) dan IEEE 802.1Q (standar industri).
Satu link trunk membawa frame bertag dari banyak VLAN

Tagging: ISL (Inter-Switch Link)

Protokol enkapsulasi tagging kepemilikan Cisco sebelum standar 802.1Q diadopsi luas:

  • Cisco Proprietary: Hanya dapat digunakan sesama perangkat Cisco murni.
  • Cara Kerja: Membungkus (mengenkapsulasi) frame asli seutuhnya ke dalam frame baru dengan menambahkan 26-byte Header di depan dan 4-byte CRC Trailer di belakang (Total overhead 30 bytes).
  • Kelemahan: Beban overhead besar dan tidak mendukung Native VLAN (frame tanpa enkapsulasi ISL akan di-drop).
ISL membungkus seluruh frame Ethernet original dengan overhead 30 bytes

Tagging: 802.1Q (Dot1Q)

Protokol penandaan frame terbuka yang menjadi standar industri global:

  • Open Standard IEEE: Kompatibel lintas vendor (Cisco, Juniper, MikroTik, HP).
  • Efisiensi Tinggi: Tidak membungkus ulang frame, melainkan menyisipkan Tag 4-byte tepat di dalam header Ethernet asli.
  • Mendukung Native VLAN: Jika ada frame tanpa tag (untagged) lewat di link trunk, frame otomatis dimasukkan ke Native VLAN (default VLAN 1).
Internal tagging 4-byte 802.1Q tanpa membungkus ulang frame

DTP (Dynamic Trunking Protocol)

DTP adalah protokol milik Cisco yang berfungsi melakukan negosiasi otomatis status port (Access vs Trunk) saat terhubung dengan port switch seberang.

Mode Access & Trunk (Hardcoded)

  • Access: Mengunci port permanen sebagai Access (non-trunk), mengabaikan tawaran seberang.
  • Trunk: Memaksa port permanen sebagai Trunk link, mengirimkan negosiasi DTP ke seberang.

Mode Dinamis (Dynamic Auto vs Desirable)

  • Dynamic Auto: Pasif. Mau menjadi Trunk hanya jika diajak aktif oleh port seberang.
  • Dynamic Desirable: Aktif. Secara proaktif membujuk port seberang untuk membentuk Trunk.
Banyak switch modern default-nya Dynamic Auto. Jika kedua sisi Dynamic Auto, trunk TIDAK akan terbentuk (menjadi Access).

Interaksi Switchport Mode (Tabel DTP)

Matriks hasil negosiasi mode switchport antar dua switch yang terhubung:

Port Lokal Port Remote Hasil Link
Dynamic Auto Dynamic Auto Access
Dynamic Auto Dynamic Desirable Trunk
Dynamic Desirable Dynamic Desirable Trunk
Trunk Dynamic Auto / Desirable Trunk
Trunk Access Error (Mismatch)
Hasil negosiasi DTP pada switchport interface

Kapan Memakai Access / Trunk?

Panduan Penerapan Mode Port

Mode Access (switchport mode access):

  • Gunakan ketika port terhubung langsung ke end-device (PC, Server, Laptop, Printer, IP Phone).
  • Hanya mengalirkan 1 VLAN spesifik tanpa disisipi tag IEEE 802.1Q (untagged).

Mode Trunk (switchport mode trunk):

  • Gunakan ketika port terhubung ke Switch lain atau ke Router (arsitektur Router-on-a-Stick).
  • Membawa trafik dari banyak VLAN sekaligus (default: VLAN 1–4094) dengan menyisipkan tag 4-byte 802.1Q.
Topologi Tipikal: Port Access ke End-Device dan Port Trunk antar Switch / Router

3. Konfigurasi Cisco IOS & Troubleshooting

Implementasi CLI, Allowed VLAN, dan Penanganan Berbagai Error Mismatch

Konfigurasi VLAN: Create & Membership

Langkah-langkah pembuatan VLAN dan pemetaan port Access pada Cisco IOS CLI:

Langkah 1: Membuat VLAN & Penamaan

Switch# configure terminal Switch(config)# vlan 10 Switch(config-vlan)# name IT_Support Switch(config-vlan)# exit

Langkah 2: Menetapkan Port sebagai Access

Switch(config)# interface FastEthernet 0/1 Switch(config-if)# switchport mode access Switch(config-if)# switchport access vlan 10 Switch(config-if)# no shutdown
Tip: Gunakan perintah interface range f0/1 - 10 jika ingin memasukkan banyak port sekaligus ke VLAN yang sama.

Konfigurasi VLAN: Delete & Verifikasi

Menghapus Port dari VLAN / Menghapus VLAN:

! Mengembalikan port ke VLAN default (VLAN 1): Switch(config-if)# no switchport access vlan ! Menghapus entitas VLAN dari switch: Switch(config)# no vlan 10
Penting: Selalu pindahkan port anggota ke VLAN lain sebelum menghapus VLAN! Port yang tertinggal di VLAN yang telah dihapus akan menjadi tidak aktif (inaktif).

Perintah Verifikasi Utama:

Switch# show vlan brief ! Memeriksa daftar VLAN aktif & port anggotanya Switch# show vlan id 10 ! Memeriksa detail spesifik VLAN 10 Switch# show interfaces status ! Memeriksa status port (vlan, duplex, speed)

Konfigurasi Trunking (Allowed VLAN)

Secara default link Trunk meloloskan seluruh VLAN (1–4094). Demi keamanan dan penghematan bandwidth, kita wajib membatasi VLAN yang diizinkan lewat (VLAN Pruning / Allowed List):

Switch(config)# interface f0/1 Switch(config-if)# switchport mode trunk Switch(config-if)# switchport trunk allowed vlan 1-20 Switch(config-if)# switchport trunk allowed vlan add 30

Hanya VLAN 1 s.d. 20 dan 30 yang diperbolehkan lewat; VLAN lain yang tidak terdaftar akan otomatis di-drop pada link trunk ini.

Filter trafik Trunk dengan parameter switchport trunk allowed vlan

Masalah Umum VLAN 1: Native VLAN Mismatch

Terjadi ketika port trunk 802.1Q di ujung kiri dan kanan memiliki konfigurasi Native VLAN yang berbeda:

  • Skenario: Switch Kiri di-set Native VLAN 10, sedangkan Switch Kanan di-set Native VLAN 20.
Dampak Bahaya:
  • Muncul pesan peringatan berulang dari protokol CDP (%CDP-4-NATIVE_VLAN_MISMATCH).
  • Terjadi kebocoran trafik: frame dari VLAN 10 di switch kiri masuk ke VLAN 20 di switch kanan tanpa melewati router!
Native VLAN Mismatch menyebabkan kebocoran cross-VLAN
Native VLAN Mismatch adalah lubang keamanan (VLAN hopping attack vector) jika tidak dikonfigurasi konsisten.

Masalah Umum VLAN 2 & 3: Mode & Allowed Mismatch

1. Trunk Mode Mismatch:

  • Satu sisi dikonfigurasi trunk, sedangkan sisi seberang dikunci access.
  • Dampak: Link putus total (broken link) karena format frame tagging tidak dikenali oleh sisi access.

2. Allowed VLAN Mismatch:

  • Trunk kiri mengizinkan VLAN 10, 20, 30; Trunk kanan hanya mengizinkan 10, 20.
  • Dampak: Pengguna VLAN 30 di switch kiri tidak bisa menghubungi host VLAN 30 di switch kanan.
Dampak kegagalan konfigurasi mode dan allowed list antar trunk

4. Metode Inter-VLAN Routing

Menghubungkan Antar-VLAN: Traditional, Router-on-a-Stick (ROAS), dan Switch Layer 3 (SVI)

Tantangan Baru: Inter-VLAN Routing

Secara desain, VLAN mengisolasi jaringan di Layer 2. Namun di dunia nyata, host VLAN 10 (Sales) seringkali perlu berkomunikasi dengan host VLAN 20 (HRD) atau mengakses Server bersama.

Karena 1 VLAN = 1 Subnet IP berbeda, Switch Layer 2 tidak memiliki kemampuan meneruskan paket antar-subnet. Diperlukan perangkat Layer 3 (Router atau Switch L3) untuk melakukan routing.

Evolusi Tiga Metode Inter-VLAN Routing:

1. Traditional

1 kabel fisik per VLAN ke router. Sangat boros port dan usang.

2. Router-on-a-Stick

1 kabel trunk fisik dengan sub-interface logikal (dot1q) di router.

3. Switch Layer 3

Routing internal hardware ASIC via SVI dengan performa wire-speed.

1. Traditional Inter-VLAN Routing

Metode generasi pertama yang digunakan saat router dan switch masih terpisah secara ketat:

  • Switch mengalokasikan 1 port Access khusus ke Router untuk VLAN 10.
  • Switch mengalokasikan 1 port Access lainnya ke Router untuk VLAN 20.
  • Router harus memiliki antarmuka fisik terpisah untuk setiap VLAN.
Kelemahan Fatal: Tidak skalabel! Jika ada 50 VLAN, router harus memiliki 50 interface fisik. Biaya sangat mahal dan port fisik terbuang percuma.
Traditional routing: 1 kabel fisik didedikasikan untuk setiap VLAN

2. Router-on-a-Stick (ROAS)

Solusi cerdas yang sangat populer untuk jaringan skala kecil dan menengah:

  • Koneksi Switch ke Router hanya menggunakan 1 Kabel Fisik Tunggal yang dikonfigurasi sebagai TRUNK.
  • Di sisi Router, satu interface fisik (misal Gig0/0) dipecah secara logika menjadi banyak Sub-Interface:
    Router(config)# interface gig0/0.10 Router(config-subif)# encapsulation dot1Q 10 Router(config-subif)# ip address 192.168.10.1 255.255.255.0
  • Tiap sub-interface bertindak sebagai Default Gateway untuk masing-masing subnet VLAN.
Router-on-a-Stick menggunakan sub-interface pada link trunk tunggal
Pastikan sintaks encapsulation dot1Q dieksekusi SEBELUM memberi IP address pada sub-interface.

3. Layer 3 Switch (Switch Virtual Interface)

Teknologi standar modern untuk jaringan kampus dan Enterprise (Multilayer Switching):

Hardware-Based Routing (ASIC)

  • Dilengkapi chip ASIC khusus yang mampu memproses routing secepat kecepatan kabel (Wire-speed performance).
  • Tidak memiliki bottleneck kabel tunggal seperti pada konsep Router-on-a-Stick.

Konfigurasi SVI (Switch Virtual Interface)

Switch(config)# ip routing Switch(config)# interface vlan 10 Switch(config-if)# ip address 192.168.10.1 255.255.255.0 Switch(config-if)# no shutdown
Perintah ip routing pada Switch Layer 3 mengaktifkan mesin routing global internal switch.
Banyak pemula lupa mengetik 'ip routing' di global config L3 switch, sehingga paket antar VLAN tetap tidak bisa routing.

Rangkuman Pertemuan 10

VLAN & Trunking
  • VLAN (Virtual LAN): Memecah switch fisik tunggal menjadi beberapa broadcast domain logikal mandiri. 1 VLAN = 1 Broadcast Domain = 1 Subnet IP.
  • Trunk Link: Menghubungkan switch-to-switch atau switch-to-router untuk mengalirkan frame dari banyak VLAN sekaligus.
  • IEEE 802.1Q: Standar terbuka penandaan frame (tagging) 4-byte (TPID 0x8100 + VLAN ID 12-bit). Mendukung Native VLAN untuk frame untagged.
  • DTP: Negosiasi otomatis mode port (Access, Trunk, Dynamic Auto, Dynamic Desirable).
Inter-VLAN Routing
  • Kebutuhan L3: Komunikasi antar-VLAN mutlak memerlukan perangkat Layer 3 karena berada di subnet IP berbeda.
  • Traditional: 1 kabel fisik per VLAN ke router — boros port fisik dan tidak skalabel.
  • Router-on-a-Stick (ROAS): 1 kabel trunk fisik dengan banyak sub-interface logikal (dot1q) di router — ideal untuk skala kecil/menengah.
  • Switch Layer 3 (SVI): Routing internal berbasis hardware ASIC melalui SVI — performa kilat (wire-speed) standar Enterprise modern.
Rangkum kembali dua pesan inti pertemuan ini: isolasi di Layer 2 dengan VLAN & Trunking, serta penyambungan kembali di Layer 3 dengan ROAS / SVI.
